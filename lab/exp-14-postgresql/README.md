# Experiment 14 — PostgreSQL

Express application connected to PostgreSQL for creating and displaying student records.

## Run

```bash
npm install
cp .env.example .env
```

Create the database, execute `schema.sql`, set `DATABASE_URL` in `.env`, and start the application with `npm run dev` or `node app.js`. Open `http://localhost:3002`.

## Concepts

PostgreSQL connections, schema creation, Express routes, parameterized SQL queries, insert/select operations and environment-based configuration.
