# Experiment 12A — Express and EJS

Server-rendered Node.js application using Express.js, EJS templates, static CSS, form handling and Nodemon.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. If needed, run `node app.js` directly.

## Concepts

Node.js, NPM, Express routes, POST requests, EJS rendering, static assets and development workflow with Nodemon.
