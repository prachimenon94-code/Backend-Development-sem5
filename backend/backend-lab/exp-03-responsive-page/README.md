# Experiment 03 — Responsive Web Page

Responsive webpage created with HTML5 and CSS3. It demonstrates semantic structure, flexible layouts, media queries, responsive navigation, cards and a mobile-friendly footer.

## Files

- `index.html` — page structure and content
- `style.css` — layout, styling and responsive breakpoints

## Run

Open `index.html` in a browser or use VS Code Live Server. No installation is required.
